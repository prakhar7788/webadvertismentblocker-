How it works

Each URL is converted into the same 1558-feature vector the models were trained on: image dimensions are imputed to the training mean, url* and ancurl* word features are extracted from the entered URL, and origurl*/alt*/caption* (not available from a URL alone) are set to zero. Each loaded model scores the vector against its own validation-tuned threshold; the combined decision is a majority vote across all loaded models. See the README for full details and limitations.
